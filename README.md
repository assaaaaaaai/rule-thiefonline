# ルール泥棒 ONLINE Ver.0.3

3〜6人が別々のスマホから招待コードで参加できるリアルタイムWebゲームのソースコードです。

## 起動方法

Node.js 18以上をインストールして、このフォルダで以下を実行します。

```bash
npm install
npm start
```

`http://localhost:3000` で表示。**別々のスマホから遊ぶには公開HTTPSサーバーにデプロイする必要があります。** ローカルPC上の localhost URLは友達のスマホからは開けません。

## 公開方法の例（Render）

1. フォルダをGitHubリポジトリにアップロード。
2. RenderでWeb Serviceを新規作成し、リポジトリを接続。
3. Build Command: `npm install` / Start Command: `npm start`。
4. 発行されたHTTPS URLを友達に共有。1人が部屋を作り、招待コードまたは招待URLを送る。

無料プラン等の仕様・スリープ・料金は公開前にRender公式で確認してください。常時稼働の保証はありません。

## 実装したルール

- 3〜6人 / 2周（人数×2ラウンド） / 8種類×3枚の法律山札
- 制定者が法律候補3枚から1枚選ぶ
- 制定者以外は数字1枚を犠牲に法律強奪へ入札（同額は制定者から時計回り優先）
- 数字勝負は秘密提出・同時公開。勝者が所有者なら2点、それ以外は1点
- 数字1〜6は使い切り。ラウンド開始時に手札0枚なら全回復
- 同点は制定者から時計回り優先
- 法律カードが3枚未満になったら捨て札を混ぜて補充
- 再接続トークンはブラウザに保存。ページ更新で復帰可能

## 試作版の制限

- サーバーのメモリ保存のみ。再起動すると部屋とスコアが消える。
- 部屋の作成者が切断すると、開始・次ラウンドの操作ができなくなる場合がある。復帰して続行する。
- 放置プレイヤーの自動スキップやターン制限は未実装。
- ログイン、観戦、ランキング、チャット、通報、不正対策、データベースは未実装。
- 公開運用前にはセキュリティ・負荷・アクセシビリティの検証が必要。
